Built for real work

claude-code

› /seo audit https://example.comFull audit with a prioritized action plan

› /seo page https://example.com/pricingDeep analysis of one critical page

› /seo geo https://example.comAI search and citation readiness

Get started

Your first audit is three commands away.

You need Claude Code 1.0.33 or newer. Add the marketplace, install the plugin, and let the setup command prepare the isolated Python runtime and browser.

No API keys are required for the core audit. Optional integrations can add live Google, Bing, Moz, and third-party data.

Run inside Claude Code
/plugin marketplace add AgriciDaniel/claude-seo
/plugin install claude-seo@agricidaniel-claude-seo
/seo setup
